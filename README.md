# Engdojo GitHub Pages

Static website for Engdojo and LingoNews.

## URLs

After publishing this repository as `engdojo.github.io`, the pages will be:

- Engdojo home: `https://engdojo.github.io/`
- LingoNews landing: `https://engdojo.github.io/lingonews/`
- LingoNews privacy policy: `https://engdojo.github.io/lingonews/privacy-policy.html`
- LingoNews support: `https://engdojo.github.io/lingonews/support.html`
- LingoNews terms: `https://engdojo.github.io/lingonews/terms.html`

## GitHub Setup

1. Create a public GitHub repository named `engdojo.github.io`.
2. Push these files to the repository's `main` branch.
3. In GitHub, open Settings -> Pages.
4. Use source: Deploy from a branch.
5. Select branch: `main`, folder: `/root`.
6. Save.

Keep the old legal URLs online until App Store Connect and app links have moved to the new URLs.
